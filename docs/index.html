FAQ · 常见问题

你可能想问

为什么需要我自己的 API Key？
DeepSeek(3rd) 没有也不运营任何后端。聊天请求由你的设备直连 api.deepseek.com，费用按官方 API 价格直接结算给你的 Key——这正是"无 7 天限制、无平台锁定"的前提。Key 在 DeepSeek 开放平台 免费创建。
我的 Key 和对话安全吗？
Key 存于 Android Keystore 支持的加密存储（EncryptedSharedPreferences），对话保存在应用私有目录，卸载即清除。应用不收集任何数据，不接入统计 SDK，网络请求只发往 api.deepseek.com 与 GitHub（更新检查）。源码公开可审计。
和 DeepSeek 官方是什么关系？
没有任何隶属关系。本项目基于官方开源的 chat-demo（MIT）移植，遵循其许可与分发要求，应用内与安装包均附带完整 LICENSE 与归属声明。"DeepSeek" 商标归深度求索公司所有，"(3rd)" 即表明第三方身份。
官方客户端的 7 天限制具体是什么？
近期官方客户端对创建超过 7 天的长对话停止续聊。API 侧没有这一产品限制——只要请求的上下文在模型窗口内，任意时间的对话都能继续。本客户端直接走 API，因此不受影响；导入官方历史 ZIP 后，老对话也能在这里接着聊。
为什么安装包这么小？有 iOS 版吗？
原生 Kotlin + Jetpack Compose，无 WebView 壳、无跨平台运行时，R8 压缩后约 3 MB（含内置 Mermaid 图表引擎与公式字体）。iOS 版暂无计划（需要苹果开发者账号与侧载分发方案），欢迎社区 fork。
免费吗？
应用本身永久免费开源。你只需支付 DeepSeek API 的按量费用（deepseek-flash 价格以官方为准），没有任何中间商加价。
